Bonjour, I am Arnaud Quillaud, from Montpellier - France.

I currently work for [Oracle](http://www.oracle.com/) as a software engineer.

In my past professional roles, I was a regular contributor to the [ical4j project](https://github.com/ical4j), a Java library that implements the iCalendar standard ([RFC5545](https://www.rfc-editor.org/rfc/rfc5545.html)).

As a side project, I am currently building a tool that aggregates road traffic data. I hope to make the repository public soon.
