Bonjour, I am Arnaud, from Montpellier, France.

## Github projects

I currently work for [Oracle](http://www.oracle.com/) as a software engineer. In my spare time, I tinker with road traffic data: [TraficInfo](https://github.com/arnaudq/traficinfo). The project has been dormant for a while. I have resurrected it as a test bed for pair programming with AI.

In my past professional roles, I was a regular contributor to the [ical4j project](https://github.com/ical4j), a Java library that implements the iCalendar standard ([RFC 5545](https://www.rfc-editor.org/rfc/rfc5545.html)).
